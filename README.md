# Finds: a Shazam concept prototype

A guided, clickable prototype from my Shazam product teardown.

**Problem:** people Shazam songs at moments when they can't listen (in a café, in a cab, while scrolling reels), and most finds are never played again.
**Concept:** *Finds* is an inbox for every tag, with a little context. A weekly mix brings the songs back, and you sort each one in a single tap: Keep, Later or Not for me.
**North Star:** find-to-listen rate, the share of new tags played or kept within 7 days.

## What's inside
- `index.html`: a single self-contained page with no build step. It walks through 8 steps: tag, today's library, Sunday notification, Finds inbox, triage, caught up, settings, and how we'd measure it.

## Run locally
Open `index.html` in a browser.

## Deploy
On Vercel: Add New → Project → import this repo → Framework preset "Other", no build command → Deploy.
